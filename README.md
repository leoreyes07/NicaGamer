# NicaGamer 🎮

*(Scroll down for Spanish version / Versión en español abajo)*

A modern, dynamic, and fully responsive web portal dedicated to gaming news, reviews, and analysis. Built with standard web technologies (Vanilla HTML, CSS, JS), with a strong focus on UI/UX aesthetics and modern design.

## 🚀 Key Features

- **Modern & Clean Design:** Revamped interface using CSS variables to control a consistent design system (rounded corners, subtle shadows, fluid hover effects).
- **Dark/Light Mode:** Native support to toggle between light and dark themes with a single click.
- **Infinite Marquee:** A CSS-only infinite scrolling news ticker in the header to highlight the latest news without dead spaces.
- **100% Responsive:** Adaptable to all screen sizes (mobile, tablet, desktop) using CSS Grid and Flexbox.
- **Complex Layout System:** Asymmetrical grids to highlight featured articles, game galleries, and a sidebar with social media widgets and popular posts.

## 🛠️ Tech Stack

- **HTML5:** Semantic and structured.
- **CSS3:** 
  - CSS Grid & Flexbox for complex layouts.
  - Custom Properties (CSS Variables) for theme management (Dark/Light mode).
  - Native Keyframe animations.
- **JavaScript (Vanilla):** Lightweight logic for the mobile hamburger menu and theme toggling.
- **FontAwesome:** Modern iconography for buttons and social media.

## 📂 Project Structure

```text
NicaGame/
├── index.html            # Main structure and page layout
├── assets/

│   ├── js/
│   │   └── menu.js       # Navbar logic and theme toggle
│   └── img/              # Game images and banners

```

## 🔧 How to Run

Being a project developed purely with native frontend technologies (Vanilla), it does not require any complex build process or dependencies.

1. Clone the repository:
   ```bash
   git clone https://github.com/leoreyes07/NicaGamer.git
   ```
2. Enter the directory:
   ```bash
   cd NicaGamer
   ```
3. Open the `index.html` file directly in your preferred web browser.
   - *Tip:* If you use Visual Studio Code, we recommend the **Live Server** extension to see changes in real-time.

# NicaGamer (Español) 🎮

Un portal web moderno, dinámico y completamente responsivo dedicado a noticias, análisis y reviews del mundo del gaming. Desarrollado con tecnologías web estándar (Vanilla HTML, CSS, JS), con un fuerte enfoque en la estética UI/UX y el diseño moderno.

## 🚀 Características Principales

- **Diseño Moderno y Limpio:** Interfaz renovada utilizando variables CSS para controlar un sistema de diseño consistente (bordes redondeados, sombras sutiles, efectos hover fluidos).
- **Dark Mode / Light Mode:** Soporte nativo para alternar entre temas claro y oscuro con un solo clic.
- **Marquesina Infinita:** Un "News Ticker" (marquesina) en la cabecera con scroll infinito puramente en CSS para destacar las últimas noticias sin espacios muertos.
- **100% Responsivo:** Adaptable a todo tipo de pantallas (móviles, tablets, escritorio) utilizando CSS Grid y Flexbox.
- **Sistema de Layout Complejo:** Grillas asimétricas para destacar artículos principales, galerías de juegos y un sidebar con widgets de redes sociales y posts populares.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Semántico y estructurado.
- **CSS3:** 
  - CSS Grid & Flexbox para layouts complejos.
  - Custom Properties (Variables CSS) para el manejo de temas (Dark/Light mode).
  - Animaciones de Keyframes nativas.
- **JavaScript (Vanilla):** Lógica ligera para el menú hamburguesa interactivo en dispositivos móviles y el toggle de temas.
- **FontAwesome:** Iconografía moderna para botones y redes sociales.
